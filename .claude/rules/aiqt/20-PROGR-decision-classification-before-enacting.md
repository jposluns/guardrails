# Decision classification before enacting

Classify a decision before enacting it: is it yours to make (ACT), the maintainer's (ASK), or blocked
(BLOCKED)? Record the classification before acting on it. When a request has more than one reasonable
reading, or needs an external value it does not pin down, surface the ambiguity in one sentence and ask,
rather than silently pick.
