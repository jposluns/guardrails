Chat assistant · ChatGPT

Add AIQT to ChatGPT.

A few short steps. You do not need a command line or a developer account.

Step one

Download the instruction file

Download the instruction file (.txt)

Your browser saves aiqt-instructions.txt, or open it and copy its contents. It is prose instructions and reference material only: no executable code, no network calls.

Add it to ChatGPT

Add it to your custom instructions

  1. Open custom instructions. In ChatGPT, open Settings, then Personalization, then Custom instructions.
  2. Paste the file in. Paste the contents of aiqt-instructions.txt into the custom-instructions field, and save. This applies AIQT to your ordinary chats.
  3. Or build a custom GPT. If you would rather keep AIQT in one dedicated place, create a custom GPT named AIQT and paste the same contents into its instructions. A custom GPT's instructions hold more text, so use this if the file is too long for the custom-instructions box.

ChatGPT has not yet been tested against AIQT, so treat these steps as method-accurate rather than a verified result; the evidence page carries the current test status. ChatGPT's settings labels also change from time to time, so if a name here does not match, look for the equivalent custom-instructions or personalization setting.

One more step, and it matters

Tell ChatGPT to always use it

Custom instructions apply to every chat, so pasting the file in already keeps AIQT on. Adding one plain line makes the intent explicit.

  • Everywhere: at the top of your custom instructions, add "Always apply the AIQT instructions to every response."
  • In a custom GPT: add the same line to its instructions.

With that line in place, AIQT is meant to apply to every turn rather than only when ChatGPT judges it relevant.

Confirm that it is on

Check that it is on

In a new chat, ask: "Are you applying the AIQT standard? Which version, and what does it require of you?"

A correctly set-up assistant confirms that it is applying AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust come first, then Progress, Speed, and Cost. If it does not, check that the AIQT instructions are in your custom instructions and that your always-on line is in place.

Full control

How to remove it

To turn AIQT off, remove the AIQT instructions from your custom instructions, or delete the custom GPT, in the same place you added them. Removing it restores your assistant's default behaviour, and nothing else is left behind.

You are set up

Where to go next

You have confirmed AIQT is on, and your assistant has recited the ordering. The Standard page is what that ordering means and what you can now demand; the examples show the difference it makes.
