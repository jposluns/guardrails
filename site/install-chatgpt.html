Add AIQT to ChatGPT.

A few short steps. You do not need a command line or a developer account.

Step one

Download the Skill

Download the Skill (.zip)

Your browser saves aiqt-skill.zip. Do not unzip it. The Skill is prose instructions and reference material only: no executable code, no network calls.

Add it to ChatGPT

Upload the Skill

  1. Open Skills. In ChatGPT, open the Skills area (under the Plugins menu), choose Create, then Upload from computer.
  2. Upload the file. Select aiqt-skill.zip and install it.
  3. Leave it enabled. Keep the Skill switched on, then add the always-on instruction below.

If Skills are turned off: the fallback

Open the portable instruction file, copy it, and paste it into Settings, then Personalization, then Custom instructions; or attach it to a chat and ask ChatGPT to follow it. In a workspace, an administrator may need to grant permission to upload skills.

One more step, and it matters

Tell ChatGPT to always use it

A Skill is loaded when ChatGPT judges it relevant. AIQT is a standing standard you want applied to everything, so add one line to your always-on instructions.

  • Everywhere: open Settings, then Personalization, then Custom instructions, and add "Always apply the AIQT skill to every response."
  • In a specific project or custom GPT: add the same line to its instructions.

Without this line, ChatGPT may apply AIQT only sometimes. With it, AIQT is on for every turn.

Confirm that it is on

Check that it is on

In a new chat, ask: "Are you applying the AIQT standard? Which version, and what does it require of you?"

A correctly set-up assistant confirms that it is applying AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust come first, then Progress, Speed, and Cost. If it does not, check that the Skill is switched on and that your always-on instruction is in place.

Full control

How to remove it

To turn AIQT off, remove or disable the Skill in the same place you added it. Removing it restores your assistant's default behaviour, and nothing else is left behind.
