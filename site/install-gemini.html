Chat assistant · Gemini

Add AIQT to Gemini.

Gemini uses a Gem. You set this up once on a computer, and it is then available on mobile too.

Step one

Download the instruction file

Download the instruction file (.txt)

Your browser saves aiqt-instructions.txt. It is prose instructions and reference material only: no executable code, no network calls.

Add it to Gemini

Create a Gem

  1. Open Gemini on a computer. Go to gemini.google.com. Gems are created on the website, not in the mobile app.
  2. Open Gems, and create one. In the left menu choose Gems, create a new Gem, and name it AIQT.
  3. Add the instruction. In the Gem's instructions, add: "Follow the AIQT instructions in the attached knowledge file for every response."
  4. Upload the file. Add aiqt-instructions.txt to the Gem's Knowledge section, then save.
  5. Use it. Once saved on the website, the AIQT Gem is available in the mobile app too.

Gemini has not yet been tested against AIQT, so treat these steps as method-accurate rather than a verified result; the evidence page carries the current test status.

One more step, and it matters

Tell Gemini to always use it

A Gem applies its instructions to every response inside that Gem, so the Gem you just made already holds AIQT to every turn. Gemini does not apply a Gem to ordinary chats automatically, so choose how you want AIQT on:

  • Start from the Gem. Open the AIQT Gem from the Gems menu whenever you want the standard applied. This is the reliable way.
  • Or add it to your personal Gemini instructions. If you would rather have it in ordinary chats, open Gemini's settings and add "Apply the AIQT standard to every response." to your saved personal instructions; the exact name of this setting varies by version and account type.

Confirm that it is on

Check that it is on

In a new chat, ask: "Are you applying the AIQT standard? Which version, and what does it require of you?"

A correctly set-up assistant confirms that it is applying AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust come first, then Progress, Speed, and Cost. If it does not, check that the AIQT Gem is switched on and that your always-on instruction is in place.

Full control

How to remove it

To turn AIQT off, remove or disable the AIQT Gem in the same place you added it. Removing it restores your assistant's default behaviour, and nothing else is left behind.

You are set up
