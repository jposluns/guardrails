Chat assistant · Any other

Add AIQT to any other assistant.

This covers local models, API-based assistants, and any system that accepts standing guidance.

Step one

Get the instruction file

Download the instruction file (.txt)

Download aiqt-instructions.txt, or open it and copy its contents. It is prose instructions and reference material only: no executable code, no network calls.

Add it

Give it to your assistant

  1. Add the file where your assistant takes standing guidance: its custom instructions, a system prompt, project knowledge, or an attached reference file.
  2. Tell it to always apply AIQT: "Use the AIQT instructions for every response unless I explicitly tell you not to."

That instruction line is the always-on step: it is what keeps AIQT applied to every response rather than only when the assistant judges it relevant.

Confirm that it is on

Check that it is on

In a new chat, ask: "Are you applying the AIQT standard? Which version, and what does it require of you?"

A correctly set-up assistant confirms that it is applying AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust come first, then Progress, Speed, and Cost. If it does not, check that your AIQT instructions are in place.

Full control

How to remove it

To turn AIQT off, remove or disable the instructions in the same place you added it. Removing it restores your assistant's default behaviour.

You are set up

Where to go next

You have confirmed AIQT is on, and your assistant has recited the ordering. The Standard page is what that ordering means and what you can now demand; the examples show the difference it makes.
