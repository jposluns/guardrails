Roadmap

Where AIQT is now, and where it is going.

One governance core, arriving in stages. What is available now, what is in development, and what we are still only considering, stated plainly so you always know which is which.

The stages

Three stages, clearly labelled

Available now

The chat assistant

AIQT 1.0.0 is one skill you load into a chat assistant that accepts one (Claude, ChatGPT, and Copilot among them). It holds that assistant to a stated standard: claims match their sources, checks keep their full strength, and "finished" has been verified before it is said. Add it to your assistant.

In development

The development assistant

Version 1.1.0, in development, installs the same governance core into a project. It generates the file each coding agent expects, sets itself up through a wizard, and ships a doctor that verifies the install. It writes only inside its own directory, so nothing else in your repository changes without your say-so. Read about the development assistant.

Ideas we are considering

Teams and Enterprise

A web console would show governance activity across projects without requiring a terminal. Enterprise management would cover what an organization needs beyond an individual: central policy, shared configuration, and reporting across teams. No dates and no commitments: an idea moves into a release only when we can say what it does and show that it works. Read about Teams & Enterprise.

How we decide

How an idea becomes a release

An idea moves into a release only when we can say exactly what it does and show that it works. Until then it is labelled as an idea, not promised as a feature. The labels above are the honest state of each stage, and they change only when the thing itself does.
