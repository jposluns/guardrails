Chat assistant · Copilot

Add AIQT to Copilot.

Microsoft 365 Copilot uses an agent. Creating one needs a Microsoft 365 Copilot licence; a no-licence fallback is below.

Step one

Download the instruction file

Download the instruction file (.txt)

Your browser saves aiqt-instructions.txt. It is prose instructions and reference material only: no executable code, no network calls.

Add it to Copilot

Create an agent

  1. Open the Agents panel. In Microsoft 365 Copilot, open the Agents panel and choose New agent.
  2. Name it AIQT.
  3. Add the instruction. "Follow the AIQT instructions in the uploaded knowledge file for every response."
  4. Upload the file. Add aiqt-instructions.txt to the agent's Knowledge section, then create or save it.
  5. Use it. Select the AIQT agent whenever you want the standard applied.

Without a licence: the fallback

Open the portable instruction file, copy its contents into a chat, and ask Copilot to follow the rules for the conversation.

One more step, and it matters

Tell Copilot to always use it

The agent applies its instructions to every response inside that agent, so the agent you just made already holds AIQT to every turn. To apply it:

  • Select the AIQT agent whenever you want the standard applied.
  • Set it centrally. If your organization manages Copilot instructions, add "Apply the AIQT standard to every response." there so it applies without selecting the agent.

Confirm that it is on

Check that it is on

In a new chat, ask: "Are you applying the AIQT standard? Which version, and what does it require of you?"

A correctly set-up assistant confirms that it is applying AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust come first, then Progress, Speed, and Cost. If it does not, check that the AIQT agent is switched on and that your always-on instruction is in place.

Full control

How to remove it

To turn AIQT off, remove or disable the AIQT agent in the same place you added it. Removing it restores your assistant's default behaviour, and nothing else is left behind.
