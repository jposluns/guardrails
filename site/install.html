Step one

Download the AIQT Skill

Everything is in one file. Download it and keep it as it is.

Download the Skill (.zip)

Your browser saves a file named aiqt-skill.zip. Do not unzip it. The Skill is prose instructions and reference material only: it contains no executable code and makes no network calls. What it changes is how your assistant behaves in conversation, nothing else, and you can switch it off in your Skills list at any time.

AIQT is a standard your assistant is required to follow, not a guarantee the model is perfect: results still depend on the platform and model, and you stay in charge. What it changes is what you can demand and check.

Claude

Set up in Claude

The recommended method. You need the file from the download step above.

  1. Turn on code execution first. The Skills section does not appear without it. Enabling code execution is Claude's requirement for using any Skill; AIQT itself contains no code to execute. In Claude, open Settings, then Capabilities, and enable code execution and file creation. Install from a desktop browser; the mobile apps are not documented to support Skill upload.
  2. Open your Skills, and create one. Go to Claude's Skills page, choose to create a new Skill, and pick "upload".
  3. Upload the file. Select the aiqt-skill.zip you just downloaded, then make sure that AIQT is switched on in your Skills list.
  4. That is it. Start a chat and every conversation is held to the standard. You can switch the Skill off at any time.

What you get

What changes once it is on

The irritations that brought you to this page are exactly what stops.

No more confident bluffing

Your assistant is required to tie each factual claim to a source, and when a guardrail catches something, it names the guardrail and what it caught.

No more guessing to please you

When your assistant does not know, it says so. When a decision is yours, it pauses and asks, instead of filling the gap with a plausible invention.

No more "done" that was not

A "done" rests on a check that actually ran, so every finished claim comes with a check you can point to.

No more quiet changes

No weakened checks, no half-built work dressed up as finished, no invented names or citations. Failures are surfaced to you first.
