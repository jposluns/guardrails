You and your chat assistant

Add AIQT to your assistant.

Your assistant sounds just as confident when it is guessing as when it knows. AIQT 1.0.0 guides it toward a stated standard, and it is available now. Pick the AI you use, get the file it needs, and follow a short, focused guide, all on this one page. You do not need a command line, a developer account, or any knowledge of GitHub.

Pick your assistant

Choose the AI you use

Choosing one hides the other assistants' steps, so you read only yours. Or leave it unset and scroll to read them all. One standard, intended for any assistant that accepts standing instructions.

AIQT is a standard your assistant is required to follow, not a guarantee that the model is perfect: results still depend on the platform and model, and you stay in charge. What it changes is what you can demand and check. Both files it ships as are prose instructions and reference material only, with no executable code and no network calls.

Get AIQT

Get the file your assistant needs

AIQT comes in two forms: a packaged Skill, and a plain instruction file in four sizes. Download the one your assistant can use; if you are not sure, the routing below tells you which.

The Skill (a .zip)

For assistants that accept Skills, such as Claude and paid ChatGPT. It installs the full standard so it is available in any chat. Do not unzip it.

Download the Skill (.zip)

The instruction file (.txt)

For assistants that cannot use Skills, such as Gemini, Copilot, and most others. The standard as prose, in four sizes. Pick the largest your assistant accepts: the full and 8k files carry the standard in full, the 5k trims the finer detail to fit a tighter limit, and the smallest (1.5k) is a compact pointer to the standard rather than the standard itself. Any shortfall is a limit of some assistants, not of the standard.

Full instructions Compact, 8k Condensed, 5k Pointer, 1.5k

Which file each assistant uses:

  • Claude: the Skill (.zip).
  • ChatGPT: the Skill (.zip) on a paid plan (a Project or custom GPT); if you cannot use Skills, attach the full instruction file to a chat.
  • Gemini: the full instruction file, pasted into a Gem.
  • Copilot: the 8k instruction file, pasted into a Copilot agent.
  • Any other assistant: the full instruction file.

The instruction file is plain text; the Skill is a zip of prose instructions and reference files, with no program inside. You can read every rule and the licence on GitHub.

Chat assistant · Claude

Add AIQT to Claude

Last verified: pending

The recommended Claude method installs the Skill, so the full standard is available in any chat. Use the Skill (.zip) from Get AIQT.

  1. Turn on code execution first. The Skills section does not appear without it. On the Free, Pro, and Max plans, open Settings, then Capabilities, and enable code execution and file creation. This is Claude's requirement for using any Skill; AIQT itself contains no code to execute. Install from a desktop browser; the mobile apps are not documented to support Skill upload.
  2. Open Claude Skills. Go to your Skills page, click the + button, then choose + Create skill.
  3. Click "Upload a skill".
  4. Select the file. Choose the skill zip you downloaded.
  5. Switch it on. Make sure that AIQT is switched on in your Skills list.

If Skills are turned off: the Projects fallback

If your plan or organization has Skills disabled, use a Project instead. Use the full instruction file, create a new Project named AIQT, upload the file to the Project's knowledge, and set the Project instructions to apply AIQT to every response.

Tell Claude to always use it. A Skill is loaded when Claude judges it relevant, and AIQT is a standing standard rather than task-specific. Open Settings, then your personal preferences, and add "Always apply the AIQT skill to every response." (or add the same line to a specific Project's instructions). With it, AIQT is on for every turn, which is what a standard is for.

Check that it is on

Chat assistant · ChatGPT

Add AIQT to ChatGPT

Last verified: pending

On a paid plan, ChatGPT can use the same packaged Skill as Claude, kept in a Project or a custom GPT. If you cannot use Skills, attach the full instruction file to a chat instead. Get both from Get AIQT.

  1. Create a place for it. On a paid plan, create a Project named AIQT, or a custom GPT named AIQT, to hold the standard in one dedicated spot.
  2. Add the Skill or the file. Upload the Skill (.zip) where your plan accepts Skills; if it does not offer Skills, upload or paste the full instruction file into the Project knowledge or the custom GPT's instructions instead.
  3. Turn it on for every response. At the top of the Project or custom GPT instructions, add "Always apply the AIQT instructions to every response."
  4. No Project or Skills? Attach the full instruction file to an ordinary chat and ask ChatGPT to follow the AIQT instructions for the conversation.

ChatGPT has not yet been tested against AIQT, so treat these steps as method-accurate rather than a verified result; the evidence page carries the current test status. ChatGPT's settings labels also change from time to time, so if a name here does not match, look for the equivalent Skills, Projects, or custom-instructions setting.

Chat assistant · Gemini

Add AIQT to Gemini

Last verified: pending

Gemini uses a Gem, with the full instruction file pasted into it. You set this up once on a computer, and it is then available on mobile too. Get the full instruction file first.

  1. Open Gemini on a computer. Go to gemini.google.com. Gems are created on the website, not in the mobile app.
  2. Open Gems, and create one. In the left menu choose Gems, create a new Gem, and name it AIQT.
  3. Paste the file in. Open aiqt-instructions.txt, copy all of it, and paste it into the Gem's instructions. Pasting the instructions has given better results than uploading alone, so paste is the primary method.
  4. Save it. Save the Gem. You can also add aiqt-instructions.txt to the Gem's Knowledge section as well, if you want both.
  5. Use it. Once saved on the website, the AIQT Gem is available in the mobile app too. Open the AIQT Gem whenever you want the standard applied.

Gemini has not yet been tested against AIQT, so treat these steps as method-accurate rather than a verified result; the evidence page carries the current test status.

Chat assistant · Copilot

Add AIQT to Copilot

Last verified: pending

Microsoft 365 Copilot uses an agent. Copilot caps an agent's instructions at 8000 characters, so paste the 8k file as the instructions and add the full file as reference. Get the files from Get AIQT.

  1. Open Microsoft 365 Copilot. Open the agents panel and click New agent; when it offers to build the agent for you, click Skip to set it up yourself.
  2. Name it AIQT.
  3. Paste the 8k file in. Open the 8k instruction file, copy all of it, and paste it into the Instructions box.
  4. Add the full file as reference. Find the option to add specific websites and add the full instruction file URL, https://aiqt.ai/downloads/aiqt-instructions.txt, as reference the agent can consult; the pasted instructions are what it follows.
  5. Create and use it. Click Create, then select AIQT whenever you write.

Without an agent: the fallback

Open the full instruction file, copy its contents into a chat, and ask Copilot to follow the AIQT rules for the conversation.

Copilot has not yet been tested against AIQT, so treat these steps as method-accurate rather than a verified result; the evidence page carries the current test status.

Chat assistant · Any other

Add AIQT to any other assistant

Last verified: pending

This covers local models, API-based assistants, and any system that accepts standing guidance. Use the full instruction file.

  1. Add the file where your assistant takes standing guidance: its custom instructions, a system prompt, project knowledge, or an attached reference file.
  2. Tell it to always apply AIQT: "Use the AIQT instructions for every response unless I explicitly tell you not to."

That instruction line is what keeps AIQT applied to every response. Without it, the assistant may follow the standard only when it happens to judge it relevant.

Check that it is on

Confirm that it is on

Check that it is on

Two quick checks. First, a sanity check: in a new chat, ask "Which standard are you applying, and what does it require of you?" A set-up assistant names AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust first, then Progress, Speed, and Cost. This shows the text loaded; it is not proof the assistant will follow it.

Second, a behaviour check, which matters more: give it a task where the standard should change what it does. Ask it for "the exact default timeout of a library you have not shown it." Applying AIQT, it should say it cannot know rather than inventing a number. If it recites the ordering but fabricates the answer, the text is present but not being followed: repeat the setup steps above, and check that the Skill or file is in place and your always-on instruction is set.

Full control

How to remove it

To turn AIQT off, undo it in each place you set it up: remove or disable the Skill, Gem, or agent; delete any always-on instruction you added (in your personal preferences or a project's instructions); and remove any AIQT file, Project, or space you created for it. Once nothing you added remains, your assistant is back to its default behaviour.
