Install the AIQT skill, step by step

Your assistant sounds just as confident when it is guessing as when it knows. AIQT 1.0.5 guides it toward a stated standard. Pick the AI you use, get the file it needs, and follow a short guide; choosing one hides the other assistants' steps.

Scope

Both shipped files are prose instructions and reference material only, with no executable code and no network calls. Claude loads a Skill when it judges the Skill relevant; an always-on instruction line instructs the assistant to apply AIQT on each turn. Results still depend on the platform and the model, and you stay in charge.

Every platform's last verified date is pending, and ChatGPT, Gemini, Copilot, and Copilot Studio have not yet been tested against AIQT. The 30 Claude Code hooks ship as an opt-in plugin; the generated adapters, a guided install, and a setup doctor arrive with the 1.1.0 developer release.

Get AIQT

Get the file your assistant needs

The Skill

aiqt-skill-1.0.6.zip

zip, 28 KB

For assistants that accept Skills, such as Claude and paid ChatGPT. Do not unzip it. The Skill carries its own version, 1.0.6, which ships under AIQT pack release 1.0.5.

The instruction file

aiqt-instructions.txt

text, full, 16 KB

For assistants that cannot use Skills. The standard as prose, in 4 sizes: the full and 8k files carry the standard in full, the 5k trims the finer detail, and the 1.5k is a compact pointer. The other sizes are compact, 8k; condensed, 5k; and pointer, 1.5k.

Claude

Add AIQT to Claude

Last verified: pending

The recommended Claude method installs the Skill, so the full standard is available in any chat.

  1. Turn on code execution first. The Skills section does not appear without it: on the Free, Pro, and Max plans, open Settings, then Capabilities, and enable code execution and file creation. AIQT itself contains no code to execute. Install from a desktop browser; the mobile apps are not documented to support Skill upload.
  2. Open Claude Skills. Go to your Skills page, click the + button, then + Create skill.
  3. Click "Upload a skill" and choose the skill zip you downloaded.
  4. Switch it on in your Skills list.

Tell Claude to always use it. Open Settings, then your personal preferences, and add "Always apply the AIQT skill to every response."

If your plan or organization has Skills disabled, use a Project with the full instruction file instead.

ChatGPT

Add AIQT to ChatGPT

Last verified: pending

On a paid plan, ChatGPT can use the same packaged Skill as Claude, kept in a Project or a custom GPT. If you cannot use Skills, attach the full instruction file to a chat instead.

  1. Create a place for it. Create a Project named AIQT, or a custom GPT named AIQT.
  2. Add the Skill or the file. Upload the Skill (.zip) where your plan accepts Skills; otherwise upload or paste the full instruction file.
  3. Turn it on for every response. At the top of the Project or custom GPT instructions, add "Always apply the AIQT instructions to every response."

ChatGPT has not yet been tested against AIQT; the evidence page carries the current test status.

Gemini

Add AIQT to Gemini

Last verified: pending

Gemini uses a Gem, with the full instruction file pasted into it. Set it up once on a computer; it is then available on mobile too.

  1. Open Gemini on a computer at gemini.google.com.
  2. Open Gems, and create one named AIQT.
  3. Paste the file in. Open aiqt-instructions.txt, copy all of it, and paste it into the Gem's instructions.
  4. Save it, and open the AIQT Gem whenever you want the standard applied.

Gemini has not yet been tested against AIQT, so treat these steps as method-accurate rather than a verified result; the evidence page carries the current test status.

Copilot

Add AIQT to Copilot

Last verified: pending

Microsoft 365 Copilot uses an agent. Copilot caps an agent's instructions at 8000 characters, so paste the 8k file as the instructions and add the full file as reference.

  1. Open Microsoft 365 Copilot, open the agents panel and click New agent; click Skip to set it up yourself.
  2. Name it AIQT and paste the 8k file into the Instructions box.
  3. Add the full file as reference: https://aiqt.ai/downloads/aiqt-instructions.txt.
  4. Create and use it. Click Create, then select AIQT whenever you write.

Copilot has not yet been tested against AIQT; the evidence page carries the current test status.

Copilot Studio

Add AIQT to Copilot Studio

Last verified: pending

Copilot Studio takes AIQT as a Skill. The zip holds a single SKILL.md at its root, the layout Copilot Studio reads.

  1. Open or create a Skills-capable agent.
  2. Add the Skill to that agent. Upload the zip in the agent's Skills.
  3. Build and link the agent to your business processes as you would any other.

AIQT's behaviour on Copilot Studio has not yet been through conformance testing; the evidence page carries the current test status.

Any other

Add AIQT to any other assistant

Last verified: pending

This covers local models, API-based assistants, and any system that accepts standing guidance. Use the full instruction file.

  1. Add the file where your assistant takes standing guidance: its custom instructions, a system prompt, project knowledge, or an attached reference file.
  2. Tell it to always apply AIQT: "Use the AIQT instructions for every response unless I explicitly tell you not to."

Confirm

Check that it is on

In a new chat, ask "Which standard are you applying, and what does it require of you?" A set-up assistant names AIQT and summarizes the ordering. This shows the text loaded; it is not proof the assistant will follow it.

Then a behaviour check: ask it for "the exact default timeout of a library you have not shown it." Applying AIQT, it should say it cannot know rather than inventing a number.
