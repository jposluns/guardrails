Install

Add AIQT to your AI development assistant

Give your development assistant 1 prompt and it prepares an adoption plan and, once you approve it, installs AIQT, with OPFiles for your project's records. Using a chat assistant? Download the Skill.

Copy this prompt

Install AIQT Guardrails in this project and walk me through adopting it. Read https://aiqt.ai/llms.txt and the repository https://github.com/jposluns/guardrails first. Propose an adoption plan: the AIQT rules, hooks, and checks that fit this project's languages and tools, and OPFiles (https://opfiles.ai/llms.txt) for the project's operational records unless I opt out. Before building any new guardrail, check whether jposluns/guardrails already has one that fits. Name every file you would create or change, and why. Change nothing until I approve the plan.

Paste it into Claude Code, Codex, Gemini CLI, Cursor, Copilot, or any other development assistant. The developer tooling is in preview: the generated adapters, a guided install, and a setup doctor arrive with the 1.1.0 developer release.

Included

OPFiles keeps your project's records straight

OPFiles (OPF) is part of AIQT Guardrails, with its own site at opfiles.ai (opens in a new tab). It keeps your backlog, findings, decisions, and handoffs in one machine-written source, generates the readable versions from it, and, where the drift check is configured as a required commit or CI check, fails the build when the 2 disagree. Your assistant always knows what was decided and what is still open.

An AIQT adoption plan includes OPF by default. It is optional: say so in your plan review and the plan skips it, and you can add it later. The reference OPF tooling cannot apply or complete an adoption yet: its apply and complete stages refuse to run, so your assistant prepares the plan and stops at the approval step rather than doing the missing stages by hand.

Requirements

What it needs

The pack's tools and hooks require Python 3.14 or newer; the development assistant page has the detail. The chat Skill needs no Python.
