Chat assistant · Claude

Add AIQT to Claude.

The recommended method, in five short steps. You do not need a command line or a developer account.

Step one

Download the Skill

Download the Skill (.zip)

Your browser saves the skill zip. Do not unzip it. The Skill is prose instructions and reference material only: no executable code, no network calls. It changes how your assistant behaves in conversation, nothing else, and you can switch it off at any time.

Add it to Claude

Upload the Skill

  1. Turn on code execution first. The Skills section does not appear without it. On the Free, Pro, and Max plans, open Settings, then Capabilities, and enable code execution and file creation. This is Claude's requirement for using any Skill; AIQT itself contains no code to execute. Install from a desktop browser; the mobile apps are not documented to support Skill upload.
  2. Open Claude Skills. Go to your Skills page, click the + button, then choose + Create skill.
  3. Click "Upload a skill".
  4. Select the file. Choose the skill zip you downloaded.
  5. Switch it on. Make sure that AIQT is switched on in your Skills list.

If Skills are turned off: the Projects fallback

If your plan or organization has Skills disabled, use a Project instead. Download the portable instruction file, create a new Project named AIQT, upload the file to the Project's knowledge, and set the Project instructions to apply AIQT to every response.

For a team on Claude: an organization owner can enable code execution and Skills in the Organization settings and upload the Skill once for the organization. That is a Claude platform feature; AIQT adds no central deployment tooling of its own yet (see the Teams & Enterprise path).

One more step, and it matters

Tell Claude to always use it

A Skill is loaded when Claude judges it relevant to the task. AIQT is not task-specific: it is a standing standard you want applied to everything. So add one line to Claude's always-on instructions.

  • Everywhere: open Settings, then your personal preferences, and add "Always apply the AIQT skill to every response."
  • In a specific Project: add the same line to that Project's instructions.

Without this line, Claude may apply AIQT only when it happens to judge it relevant. With it, AIQT is on for every turn, which is what a standard is for.

Confirm that it is on

Check that it is on

In a new chat, ask: "Are you applying the AIQT standard? Which version, and what does it require of you?"

A correctly set-up assistant confirms that it is applying AIQT and summarizes the ordering: Accuracy, Integrity, Quality, and Trust come first, then Progress, Speed, and Cost. If it does not, check that the Skill is switched on and that your always-on instruction is in place.

Full control

How to remove it

To turn AIQT off, remove or disable the Skill in the same place you added it. Removing it restores your assistant's default behaviour, and nothing else is left behind.

You are set up
