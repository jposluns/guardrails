# Changelog: AIQT Guardrails™

The user-facing changes for each public release.

## 1.0.0: The chat-assistant skill (2026-08-12)

- AIQT 1.0.0 ships the chat assistant: the AIQT governance core packaged for a chat assistant, as a Skill you upload to Claude or a portable instruction file for other assistants (ChatGPT, Copilot, Gemini). It guides the assistant toward the AIQT standard: claims matched to their sources, checks kept at full strength, and "finished" verified before it is said. The evidence page shows what has been tested on each platform.
- Includes the portable AIQT governance core and a curated security-rule subset for chat use.
