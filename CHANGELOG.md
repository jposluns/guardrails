# Changelog: AIQT Guardrails

The user-facing changes for each public release.

## 1.0.0: The chat-assistant skill (2026-08-12)

- AIQT 1.0.0 ships the chat-assistant skill: one skill you load into a chat assistant (Claude, ChatGPT, and Copilot among them) that holds it to the AIQT standard, so claims match their sources, checks keep their full strength, and "finished" is verified before it is said.
- Includes the portable AIQT governance core and a curated security-rule subset for chat use.
