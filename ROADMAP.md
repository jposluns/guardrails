# AIQT Guardrails roadmap

What you can use today, what is being built, and what is only an idea, each labelled. The label changes only when the thing itself does.

## Available now: The chat assistant

You can have this today. AIQT 1.0.0 is one skill you load into a chat assistant that accepts one (Claude, ChatGPT, and Copilot among them). It holds that assistant to a stated standard: claims match their sources, checks keep their full strength, and "finished" has been verified before it is said. [Add it to your assistant.](https://aiqt.ai/install)

## In development: The development assistant

Version 1.1.0, in development, installs the same governance core into a project. It generates the file each coding agent expects, sets itself up through a wizard, and ships a doctor that verifies the install. It writes only inside its own directory, so nothing else in your repository changes without your say-so. [Read about the development assistant.](https://aiqt.ai/development)

## Ideas we are considering: Teams and Enterprise

A web console would show governance activity across projects without requiring a terminal. Enterprise management would cover what an organization needs beyond an individual: central policy, shared configuration, and reporting across teams. No dates and no commitments. [Read about Teams & Enterprise.](https://aiqt.ai/teams)
